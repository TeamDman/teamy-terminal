# Embedded font provenance

`CaskaydiaCoveNerdFontMono-Regular.ttf` is the regular monospace face from
the official Nerd Fonts v3.4.0 CascadiaCode release:

<https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/CascadiaCode.zip>

The accompanying `CaskaydiaCoveNerdFont-LICENSE.txt` is copied from that
release archive. The application embeds only the regular monospace face.
